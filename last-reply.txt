件名: 枠 百七十五：鈴の間を空ける役を VAIO の見張りへ移す（合図が続けて鳴っても起こすのは一度・積んだ分をまとめて受領）

Frame 175 is done and its card is out. The job of spacing out the bell now lives in the VAIO watcher's waker (`rewake.js`), so センコ can ring the bell as soon as they write a frame.

- **How it works:** when the only new inbox lines are bridge bells, it won't wake the window if it woke it within the last 180 seconds. The bells aren't dropped. They stay in the inbox as unprocessed lines. Once the gap has passed it wakes the window once for all of them, and the window reads every new frame. If the window is busy it still waits, as before. Other wakes, such as a cloud run finishing or queue items, still happen immediately.
- **Test:** I ran it against a fake setup with the gap shortened to 4 seconds. Bell A woke it, bell B right after was held with the log line "積んでおく", and then B and C went through together as one wake covering 2 bells. The test is `scratchpad/rewake-bell-test.js` and is pushed. I didn't test the real 180-second case or a real bell.
- **When it takes effect:** the change applies from the next time a waker starts, which is the next time the window stops.
- **Not changed:** the watcher's backup route (`inbox-watch.ps1` sending text when no waker is running) is untouched, so it works as before. If a voice call dropped the waker, the old behaviour applies until a waker is up again.
