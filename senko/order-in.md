# 枠：棚 #16 段2/3 染め（混一色・清一色）の相手ありの測りと助言の文案

棚 #16（koushu-ops）の二段目。国士・四暗刻でやった相手ありの測り（枠 百五十七・百八十九）と同じ作りで、染めを測る。
一、配牌の形ごとに「同じ色（＋字牌）が何枚から染めるか」を、押し切った時と普通に打った時で、同じ山で和了・放銃・平均点を比べる。よその覚え書きの「同じ色7枚」は測った数ではないので、自前で測る。重い測りは雲のこの走りの中で回す。
二、結果の表を reports/ に置く（段1 と別のファイル）。
三、表から「どう打つか」の助言の文案を作る（七文と同じ形・言い切り）。本体と声には入れない。
手数30。収まらなければ、どこまで済んだかを札に書いて止める。札に表の要点・文案・押した sha を書く。
